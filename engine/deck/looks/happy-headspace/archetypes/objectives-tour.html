The goal
Deck mark

Climb it out loud. The blocks rise because the objectives build on each other - say what each one made possible for the next, not just what it was.

Be honest about where you are. Point at the block the marker is resting on and say what is left. A half-finished objective said plainly is stronger than four ticks.

Prepare the question "what if the last one fails?" - have the fallback ready in one sentence, and say it calmly. This look makes an honest answer sound like an honest answer.
