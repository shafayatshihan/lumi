Deck mark

Read the axis first. Say what is up the side before you say a single number, and say that every block is measured from the same flat baseline - that is why they can be compared at all.

Then read the chips in order - they are the order the eye should travel. Name the one block the slide is about and say what made it different.

Source every number aloud and say plainly if the shape is illustrative. If asked for a value between two bars, say the data does not resolve it rather than inventing one.
